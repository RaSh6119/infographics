# Supplementary icons

Ten icons from Google's Material Symbols (https://github.com/google/material-design-icons, commit
10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7, style "Material Symbols Rounded", filled, 48 px),
licensed under the Apache License 2.0 (LICENSE in this folder).

They add general symbols that Health Icons lacks: clock, hourglass, alarm clock, arrows down / up /
right, percent, a "no" sign, a shield with a checkmark, and a calendar with a checkmark.

Modifications, made when the icon index is built (scripts/build_icon_index.py), not to these files:
each path gets `fill="currentColor"` so the icon takes the page's CSS colour, and the fixed width and
height are removed so the page can size it.
